# サンプルボイス 引き継ぎメモ（Claude Code向け）

各キャラの個別ページに「サンプルボイス」欄がある。台本は `data/characters.json` の
`voices`（全年齢）と `r18_voices`（成人向け）。音声ファイルを置くと、その番号のセリフに再生ボタンが付く。

## 置き場所

| 種類 | 置き場所 | 送り方 |
|---|---|---|
| 全年齢 | リポジトリの `audio/<id>/01.mp3` など | コミットして push（自動で反映） |
| 成人向け | **リポジトリの外** `E:\r18_voice\<id>\01.mp3` など | `python tools/upload_r18.py E:\r18_voice --audio`（FTPS直送） |

- ファイル名は台本の番号（`01`, `02`, `03`）に合わせる
- 形式は mp3（128kbps程度、1本 数十KB〜300KB）。m4a / ogg も可。成人向けは wav なら ffmpeg で mp3 に変換して送られる
- 成人向けの音声は GitHub に入れない（`.gitignore` と自動反映の除外に `r18/audio/` を入れてある）
- 音量はキャラ間でそろえる（ラウドネス -16 LUFS 前後が目安）。頭と末尾の無音は短めに

## 音声の作り方（AI音声）

- VOICEVOX、Style-Bert-VITS2、COEIROINK など、本人（あかり）が使うソフトで作る
- **利用規約を必ず確認する**。特に次の2点
  - 商用利用（サイトは作品の宣伝・販売につながる）が許可されているか
  - **成人向けの内容に使ってよいか**（VOICEVOX のキャラクター音声などは、キャラごとに性的な用途を禁止・制限していることがある）
- クレジット表記が必要なソフト・話者なら、`data/characters.json` の `voice_credit` に書く（例：`VOICEVOX:〇〇`）。ページの音声欄の下に表示される
- 演技は下の「声の演技メモ」を参考に。キャラごとに話者や話速・抑揚をそろえる
- 生成したら本人に聞いてもらって、選んだものだけを置く

## 作成済みの音声（2026-11-26、Irodori-TTS v4.1-Small）

- ソフト：Irodori-TTS v4.1-Small（`D:\irodori\Irodori-TTS`）。重み・コードとも MIT。商用利用可、成人向けの禁止規定なし（禁止は同意のない実在人物の声のなりすまし・欺瞞目的のディープフェイク）。生成音声のクレジット表記は不要なので `voice_credit` は空。生成音声には不可視の電子透かし（SilentCipher）が入る
- 参照音声はすべて Irodori のキャプションだけで作った声（実在の人の声は使っていない）。置き場所は `D:\irodorioice_library\library\_参照音声\`
- 作り方：`D:\irodorioice_library	oolssari_voice.py`（話者・台本の読み・感情指定はこの中の `CHOSEN` と `LINE_TUNE`）→ 確認ページで選ぶ → `toolssari_finish.py`（頭末尾の無音を詰める、-16 LUFS（2パス loudnorm）、mp3 128kbps モノラル）
- 共通設定：cfg_caption 6.5 / cfg_speaker 2.5、キャプション＝キャラのキャプション＋行ごとの感情指定、行頭に演技の絵文字。同じセリフをシードを変えて3テイク作り、本人が選んだ
- 作り直すときは同じ設定・同じシード（20261126 + テイク番号×101）で再現できる
